## 模块说明

### 1. Google 多账号目录
在「设置 › 账号目录」集中管理多个 Google 账号，不再混用单一全局凭据。每个账号独立维护 Colab 与 Drive 授权状态，支持单独开启或关闭任务分配、设置站内估算 CU 安全预算，并在解除连接前自动检查活动资源，防止误删正在运行的任务或丢失历史作品归属。
- 新增账号别名并分别完成授权
- 独立开关允许使用与允许分配
- 设置单账号每日安全预算上限
- 安全检查通过后才允许解除连接

### 2. 实例中心与常开保留（Retain）
在「算力」与「设置」页面均可查看实例中心，将机器生命周期从单次任务中解耦。开启保留策略后，任务完成时机器进入「保留空闲」状态并按设定分钟数倒计时；后续同指纹任务可直接复用该实例并跳过环境与模型恢复，完成后自动顺延空闲截止时间。手动停止或空闲到期后，由服务端与 Watchdog 确认远端释放并记录用量账本。
- 全宽单列展示实例状态与短ID
- 支持按全部、活动、保留、历史筛选
- 展开详情秒看关联任务与事件流
- 手动停止需待远端确认后标已删除

### 3. 运行选择与受控工作台
在「创作 › 运行设置」中可直接选择目标账号、兼容实例与完成后的保留策略（节省 / 批次 / 智能 / 保留）。实例中心提供受控工作台入口，仅通过服务端白名单接口读取受审查工作流参数、产物与脱敏日志，绝不向浏览器暴露底层 Runtime 连接令牌或开放任意代码执行。
- 创作页支持指定账号与复用机器
- 支持设置1至30分钟空闲保留时长
- 受控工作台支持查看参数与日志
- 历史或未验证实例自动强制只读
