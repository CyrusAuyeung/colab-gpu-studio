## 已有“释放中”实例的恢复

1. 暂停提交新任务，停止旧版 worker/watchdog。
2. 备份数据库、`.env` 与相关数据目录，保留原 `ENCRYPTION_KEY`。
3. 更新至本提交或后续包含此修复的版本，按原部署方式重启 API、worker 与 watchdog。
4. 等待 watchdog 巡检并刷新实例列表。

自动恢复要求实例与租约属于同一用户、账号 ID 非空且一致，租约的实例关联与当前实例一致，关联租约已标记 `deleted`，并保存了 provider 明确确认远端删除的 `remote_deleted` 及可信来源记录。满足条件的 `releasing` / `cleanup_pending` 实例会安全收敛为 `deleted`，不再计入活跃实例预留预算；重复巡检不会重复结算。

仅有 `deleted` 状态、普通 404、网络异常、缺失账号或租约关联均不足以自动确认远端删除。旧数据缺少上述证据时可能仍保留“释放中”，请提供脱敏后的实例、任务及租约 ID 和相关日志进一步核对；不要清空数据库、重新生成加密密钥或直接执行批量 UPDATE/DELETE。
