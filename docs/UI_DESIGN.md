# 390px 移动应用设计规范

本轮采用 Taste Skill 2.5.0 的一致边缘、清晰动作、真实内容和多宽度浏览器审阅方法。来源是 Leonxlnx/taste-skill 的实际 SKILL.md。它以营销网站为主，其整屏 Hero、强制照片、shader、循环 hover 动效、禁止图下注释和 HTML starter 不适用于本应用：按任务规格保留 React 应用、参数及作品元信息，采用安静无渐变、无玻璃的实用界面。

390px 信息层级：

1. 创作：项目与 Mock 状态 → 工作流 → 参考素材 → 动态参数 → 批次数量/策略 → 风险说明 → 提交。
2. 任务：活动任务数量 → 搜索/状态 → 阶段卡片 → 详情、取消、重试。
3. 作品：当前项目 → 类型过滤 → 按需网格 → 全屏详情及参数、下载、删除。
4. 算力：明确 Mock 标签 → 当前租约 → 预算与策略解释 → 诊断与设置入口。
5. 设置：主题 → Google 客户端配置与安全状态 → 工作流管理 → 退出。

底部四导航固定，设置从顶栏进入。触控目标至少44px，正文1rem，辅助文字0.875rem，标题1.25–1.5rem；系统中文字体与等宽数字。间距以0.25rem递增，主间距1rem，输入圆角0.625rem，卡片0.875rem。深色背景#101514、文本#edf4ef、辅助#b0beb6、强调#74c8ab；浅色单独定义。所有输入有可见focus，长内容换行，手机单列，安全区留白，底部操作不得覆盖表单。

验收必须使用本地 API + Mock Provider，多宽度深浅主题截图、真实点击、Console及溢出检查；本文设计不构成已验收声明。
