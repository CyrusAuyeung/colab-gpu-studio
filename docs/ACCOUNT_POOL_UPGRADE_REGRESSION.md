## OAuth 多账号配置补修

截图反馈的跨账号配置拦截已补修。设置页增加“共享默认应用 / 指定账号”选择，GET/POST 同步传递 account_id 并验证账号归属。账号 A 已连接时可以给 B 保存不同应用，B 的配置不覆盖 A 的旧应用及令牌；目标账号已连接且确实更换客户端时仍拒绝。历史迁移应用相同值重存通过，账号专属应用不会变为其他账号的共享回退。保存配置只失效受影响的待授权 state。并发检查和保存置于同一调度锁。

新增 OAuth API/服务回归及浏览器保存流程。最终 gen2 后端全量 365 passed、2 条既有 warning；前端构建通过、16 项前端 GPU/API 回归通过；390×844 Chromium 实际选择 B 保存返回 200，A 保持连接，无页面错误。无真实 Google 请求。最终证据以 closing-results.json、closing-0.log 至 closing-6.log、browser-oauth-scope.json 为准；早期 oauth-* 日志仅作历史。最后两项审查边界均先复现失败、修复后通过，21 项 OAuth 定向回归与最终 365 项全量通过。独立只读复审通过，无新的安全或逻辑问题。最后源码再次通过四条真实旧库升级及连续重启断言，23 个变更代码/测试文件与 gen2 SHA-256 一致。
