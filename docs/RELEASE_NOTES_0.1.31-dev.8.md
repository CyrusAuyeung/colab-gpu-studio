# Colab GPU Studio 0.1.31-dev.8

**发布日期：** 2026-11-05  
**在线服务：** [gpu.tizenty.xyz](https://gpu.tizenty.xyz)

本次版本合并界面重做与运行时稳定性改进，面向日常创作使用。以下为正式更新说明。

---

## 新增功能

### 批次连续出图
同一工作流的多张任务可在同一台 GPU 上连续执行：前一张完成后直接交接给下一张，无需反复开机，缩短等待并降低算力消耗。

### 同模型智能复用
在同一台仍在运行的机器上，若后续任务使用相同的模型与环境，将自动识别并跳过重复的模型文件恢复，进一步节省时间与 CU。

### 项目记忆与快捷切换
- 刷新页面后仍保留上次所选项目  
- 点击右上角项目名称即可切换  
- 旁侧「＋」可快速新建项目  

---

## 界面更新

创作站整体改为黑白极简风格，默认深色，并可在设置中切换浅色或跟随系统。

**创作页**
- 画面比例改为带预览的胶囊选项；自定义宽高仅在需要时出现  
- 尺寸选项去重，交互更稳定  
- 高级参数默认折叠，界面更清爽  
- 关键与操作文案统一为简短中文，关键模式附带说明  

**工作流管理**
- 按模型分组折叠，同一模型的多个版本集中展示并支持分页  

**图库与视频库**
- 缩略图居中裁切、去除白边  
- 选中后可预览、再次生成或删除（删除需确认）  

**算力页**
- 「检查可用 GPU」会明确展示结果或错误信息  

---

## 稳定性与体验修复

- 修复批次交接时偶发的机器归属错误，避免第二张及后续任务卡在清理阶段  
- 离线或未启用真实 GPU 时，相关接口返回清晰提示，不再出现无反馈或异常失败  
- 算力检查结果与错误均可在页面直接查看  

---

## 使用提示

1. 真实出图前，请将运行方式切换为 **Colab GPU**（默认仍为模拟）。  
2. 模型复用仅在同一台尚未关机的机器上生效；机器关闭或更换工作流 / 模型后会重新准备环境。  
3. 批次可减少重复开机，但每个任务仍会按流程启动推理环境。  
4. 部分长视频精修（例如 15 秒）在部分 GPU 型号上仍可能因显存或超时失败，请以实际任务状态为准。
