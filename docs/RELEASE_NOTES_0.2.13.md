# 0.2.13 更新说明

- 向导关闭后恢复原任务
- 成功冒烟直接续接验收

## 升级与恢复

更新前备份数据库和 `.env`，保留原加密配置。进行中的冒烟任务保留原 job ID，返回工作流管理后重新打开向导即可恢复；已完成任务继续验收，无需重新分配 GPU。模板、模型 revision 或受审查依赖有变化时，旧冒烟证据不得用于当前版本。

离线图预览只读取本地受审查内容，不启动实例、不执行节点。历史日志读取站内持久记录；实例删除前未采集的远端日志无法凭空恢复。

插件只接受管理员安装并明确允许的固定入口，示例生成明确标记的离线 JSON 测试产物，不代表 Laya GPU 基准或真实模型执行。配置契约见 `TRUSTED_EXECUTOR_PLUGIN_CONTRACT.md`。

v0.2.13 已发布；后端全量 425 项、前端 33 项测试通过，前端构建及 GPU 契约检查通过。浏览器隔离测试覆盖向导关闭重开、成功验收且无新冒烟创建请求、手机尺寸节点图、实时工作台不可用时读取历史日志。未启动真实 GPU、未进行真实 Google OAuth 交换；生产部署未改。
