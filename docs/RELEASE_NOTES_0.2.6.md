# 0.2.6 更新说明

## 新功能：网页一键启用内置草稿

以前要把内置草稿变成可用工作流，只能照 `docs/BUILTIN_WORKFLOWS.md` 用 curl 依次调管理员接口
（校验 → 模型审查 → 工作流审查 → 真实冒烟 → 验收 → 发布），普通用户很容易卡住。

- `工作流` 页面每个未发布版本右侧新增 **一键启用**，展开为五步向导：
  1. 校验模板
  2. 确认模型来源与许可
  3. 锁定权重、ComfyUI commit 与节点白名单
  4. 真实 GPU 冒烟（最长 5 分钟，按分钟计费）
  5. 验收冒烟结果并发布为当前版本
- 必须勾选「我知道会真实开 GPU 并产生费用」才会执行；冒烟阶段前端自动轮询任务状态，
  完成后自动验收并发布，失败停在该步并显示原因，可重试。
- 新增只读接口 `GET /api/gpu/workflows/{id}/activation`：返回各步完成状态、最近一次冒烟任务、
  服务端阻塞原因（未开真实 GPU、未配置费率、模型缺来源或许可）。该接口不批准、不分配 GPU、不写证据。

## 变更

- 工作流页原有「校验 / 发布」按钮保留，供排查和手动操作。
- `docs/BUILTIN_WORKFLOWS.md` 第 3 节改写为网页一键启用，curl 流程保留为排查用。
