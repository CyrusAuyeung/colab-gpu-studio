本轮本地输出：LocalArtifactStore 支持分块与校验，调度器接受本地/Mock 清单并创建私有图库资产；真实 Drive 清单明确拒绝，不伪造已持久化。MCP 状态探针优先转发清单，旧小输出保留 100MiB Base64 兼容路径。Worker run_job 已支持显式注入对象存储，离线150MiB文件生产清单与断点续传验证通过，Comfy输出下载改1MiB分块落盘；该测试替换了采样函数，没有运行Comfy/CUDA。远程CLI/MCP启动尚未注入云存储适配器，真实Worker分块直传仍未完成。

任何旧测试/脚本需要真实授权或真实 Runtime 时必须暂停，不得通过开启 GPU_REAL_ENABLED 继续。本地测试仅允许纯假配置对象与注入适配器测试策略分支；环境开关保持 0。
