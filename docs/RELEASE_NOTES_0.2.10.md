# 0.2.10 更新说明

- 同步版本与依赖锁版本

## 问题与修复

通过网页设置保存 Google OAuth 应用后，配置记录属于当前 owner，不绑定具体 Google 账号。新增账号的授权服务此前只读取账号绑定的应用配置，因此在没有环境变量配置时，设置页显示“已配置”，点击 Colab 或 Drive 授权仍会返回 `503 GOOGLE_ACCOUNT_ERROR`（Google OAuth 未配置），前端随后显示“授权尚未开始；再次重试会复用同一幂等键。”。

修复后的读取顺序为：账号专属应用配置 → 同一 owner 未绑定账号的共享应用配置 → 环境变量。账号 access token、refresh token、OAuth state 的归属与隔离逻辑不变，不读取其他 owner 或其他账号的应用配置，已撤销配置不可用。

## 验证范围

本版本全量后端测试 328 项通过，前端构建与接口契约检查通过。

新增回归测试覆盖网页保存配置后新增账号的 Colab / Drive 授权、同一幂等键复用、无登录 owner 的回调按 state 找回正确账号、账号专属配置优先，以及跨 owner、跨账号和已撤销配置的隔离。

授权回调中的 Google token 交换使用测试传输；这不代表真实 Google 账号授权或真实 GPU 已验收。本次修复不包含启动 GPU 或修改线上数据。
